HARDBALL

Local HTML demo · no server

Pick two city clubs, then watch the game unfold on a diamond — Gamecast-style, play by play. Platoon, pen, park, gloves, and baserunning are live. Full draft leagues come with the Next.js app.

Open demo/index.html or run npm run demo. Star pool (~75 careers). Not pitch-by-pitch yet — each PA / steal / pitching change animates.
