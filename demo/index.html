HARDBALL

Local HTML demo · 16-bit / 64-bit Gamecast

Pick two city clubs, then watch a retro diamond Gamecast. Toggle 16-bit (SNES chunky) or 64-bit (smoother HUD). Platoon, pen, park, gloves, and baserunning are live.

Open demo/index.html or run npm run demo. Star pool (~75 careers). Not pitch-by-pitch yet — each PA / steal / pitching change animates.
