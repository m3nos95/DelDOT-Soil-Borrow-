HARDBALL

Local HTML demo · no server

Pick two city clubs, auto-build career lineups from a star subset, and sim a game in your browser. Platoon, stamina, and bullpen roles are live. When you want drafts and friends, use the full Next.js app.

Open demo/index.html in a browser, or run npm run demo from the repo. Star pool only (~75 careers). Full ~23k set is in the online app.
